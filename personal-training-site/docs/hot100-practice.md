# Hot100 面试手撕训练

打开 `/algorithm` 使用每日五题、快速回忆或混合训练；题目页默认隐藏题型和答案。

## 核心代码 / ACM 模式

Hot100 每题顶部可切换两种模式，也可通过 `?mode=acm` 直接进入完整程序模式。

- 核心代码模式：实现函数或类，平台构造参数、调用入口、校验返回值和节点身份。
- ACM 模式：自己读取 `stdin`、解析数据、导入标准库、构造链表/树并打印 `stdout`，运行器不会自动调用 solve，也不会注入 ListNode、TreeNode 或 typing。
- 两种模式的草稿、计时、提示层级、作答历史和复习间隔分别保存。旧版未带 mode 的记录保留为核心代码模式。切换模式不会沿用另一种模式的测试结果。
- ACM 自定义用例直接填写多行原始输入和预期输出，不需要 JSON 转义。每个用例单独初始化 stdin 和程序命名空间，支持 `input()`、`sys.stdin.readline()`、迭代 stdin 和 `sys.stdin.buffer.read()`。
- Hot100 原题是函数接口，ACM 输入输出由本站逐题定义；常规数字/数组/网格使用文本格式，复杂嵌套结构、树、设计类题有明确的 JSON 行约定。节点身份与原地修改等内存约束请使用核心代码模式验证。
- 普通 I/O 专项保留分行，容忍每行首尾及重复空白、CRLF、末尾换行差异；额外提示语、不正确的输出行数会判错。Hot100 的回文、多解、无序集合等按语义校验。

首页新增 8 个本地 I/O 关卡：固定 T 组、EOF、0 0 结束标记、N 个数求和、单词排序、非标数组清洗、字符网格、链表构造和箭头格式化输出。每关五个测试，包含空输入、空行、负数、跨行、无末尾换行及终止标记。N 个数求和沿用本地题意，N=0 为结束标记，不输出。

专项题面和 TODO 骨架来自 `C:\Project\leetcode\acm_mode\exercises`；可运行参考解和补充边界测试明确作为整理补充保存，未修改本地文件。

运行 `npm run dev` 启动网站。首次运行 Python 会加载随站点发布的 Pyodide 0.27.7（CPython 3.12），之后使用浏览器资源缓存；不需要 Python 后端。只支持标准库。停止执行会销毁 Worker，下一次运行重新初始化。编辑区可按 Ctrl+Enter 运行。

标准库以 `.data` 静态资源发布，加载时验证 SHA-256 后通过 Blob URL 交给解释器，避免部分浏览器读取 `.zip` 时得到空响应而报缺少 encodings。

## 同步本地题解

源目录默认 `C:\Project\leetcode`，可通过 `LEETCODE_ROOT` 指定。同步只读取 Python 文件和 Hot100 进度表，不修改它们。

```powershell
$env:LEETCODE_FETCH='0'
npm run generate:algorithms
npm run generate:practice
npm run generate:acm
```

以上依次更新历史资料库、核心代码训练快照、ACM 契约和专项。100 题官方清单固定在 `src/data/practice/hot100.json`，不从本地完成数量推断。显式运行 `python scripts/fetch-hot100.py` 才刷新官方题单；题单发生变更时还必须补齐运行契约及测试后才能通过验收。

如需从官方刷新完整题面，可先运行 `python scripts/fetch-practice-statements.py`，然后依次执行上述生成命令。导入保留段落边界与指数表示，例如 `10^4` 不会被压成 `104`。

`scripts/practice-cases.py` 保存独立预期结果与小规模组合枚举，`scripts/practice-recall.py` 为逐题整理补充笔记。原始注释与编辑补充明确区分；没有明确记载的错误原因、修正和反例不自动编造。文件内容摘要变化时标记回忆卡待核对。

官方题单新增于本地题单之外的 23、62、64 提供补充参考实现。2 的本地实现未完成循环推进，因此保留原始版本供对照，并用标明来源的补充实现作为可运行参考。

## 运行契约

每题提供五个本站用例。普通题的位置参数用 JSON 数组传入；链表为数组，树为层序数组，null 表示空节点。

- 环链表：`[值数组, 环入口下标]`，无环填 -1；142 的预期为下标或 null。
- 相交链表：`[前缀A, 前缀B, 共享尾部]`，预期填 true，校验器检查返回的是否是真正共享节点（无交点应为 None）。
- 随机链表：`[[[值, random下标], ...]]`；校验深拷贝、原链表未改变、random 未指向原节点。
- 最近公共祖先：`[树数组, p的数组下标, q的数组下标]`，预期为祖先下标；校验节点身份。
- 设计题：`[操作名称数组, 参数数组]`，第一项必须是构造函数，预期也是操作返回值数组。
- 最长回文子串：预期填最长长度，接受任意同长度合法回文；平衡 BST：预期 true，检查中序和高度平衡。
- 原地题校验修改后的参数；组合和无序集合使用对应校验规则。

初始化限时 60 秒，执行整套测试限时 10 秒。本站小规模用例用于面试练习，不替代 LeetCode 全量判题与复杂度要求。语法错误、运行异常、答案错误会分别显示，输出最多保存 16000 字符。

## 数据与验证

草稿、提示层级、计时、作答历史存于 IndexedDB；旧间隔复习记录继续使用原有 localStorage 键。已归档的作答须重新练习才能再次记录，避免重复点击延长间隔。解释成绩单独保存。

首页可导出/导入版本 1 JSON 备份。导入前检查结构，按时间合并较新草稿，历史作答按唯一键合并；无效版本或题号不会写入。浏览器存储失败时提供明确提示及代码下载。

```powershell
npx tsc -b
npm run lint
npm test
python scripts/test-practice-harness.py
python scripts/test-acm-harness.py
python scripts/verify-practice.py
python scripts/verify-acm.py
node scripts/verify-practice-wasm.mjs
npm run build:pages
```

测试覆盖全部参考解、空模板拒绝、节点身份、合法多解、无序输出、原地操作、典型错误变体、用例隔离、输出限制、初始化/运行超时、停止后重跑、提示限制、存储和备份合并。

个人错误复习：每次返回失败结果时自动保留当时的代码与测试现场。点击“记住这次错误”，由本人确认原因、自检问题及标签后加入复习。当前代码通过完整本站测试时，保存错误卡可一并保留修正代码并查看变化范围。下次练习先做旧错自检，查看失败详情计为提示。错误卡作为历史作答的可选字段，兼容既有 version 1 JSON 备份，不回写本地源文件。停止或超时尚未返回测试现场时，仍保留草稿，不伪造失败输入输出。
