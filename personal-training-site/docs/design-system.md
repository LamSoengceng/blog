# 全站视觉规范

共享变量位于 `src/index.css`，页面映射位于 `src/styles/design-system.css`，在 `App.css` 之后全局加载。算法训练通过同一组变量取色，不另建主题。

- 页面 / 卡片 / 输入底色：`--page`、`--surface`、`--control-bg`。
- 主要 / 辅助文字：`--text`、`--text-strong`、`--muted`。
- 操作与选中态：`--accent`、`--accent-soft`、`--text-on-accent`。
- 边线 / 圆角 / 阴影：`--border`、`--border-strong`、`--radius-card`、`--radius-control`、`--shadow-card`。
- 内页标题桌面 30–44px、手机 30px；首页保留展示型主标题。卡片 16px 圆角、控件 9px 圆角。
- 主操作为薄荷绿实底，次操作为透明底与细边框；删除、停止和风险保留警示色。股票涨跌、图表序列与题目难度颜色保留业务含义。
- 页面顶部必须避开固定导航：桌面导航 76px，手机 68px。内页与训练页分别保留适当呼吸空间。
- 新页面优先使用共享变量和已有组件样式；页面自身只负责布局，不再增加独立配色。新增样式按模块写在公共映射中，避免修改图表、代码高亮和媒体内容。
- 验收：桌面 / 手机、表单焦点、按钮禁用与选中、弹窗、长标题、列表与图表横向溢出、减少动效偏好。
