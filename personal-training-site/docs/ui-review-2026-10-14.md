# 界面与易用性检查（2026-10-14）

本轮检查依据：源码、现有自动化测试，以及用户提供的「问我的站」截图。浏览器访问权限未获准，没有完成真实浏览器截图、不同屏宽的视觉检查或真实 AI 接口调用。

| 问题 | 改进 | 验证方式 |
| --- | --- | --- |
| AI 回答直接放进 `<p>`，`**加粗**` 和列表标记原样显示 | 共用 Markdown 渲染组件，覆盖站内问答、算法 AI 回答、费曼评语与历史评语 | 使用模拟 AI 回复重现截图中的格式；验证生成 strong、列表、代码和表格 |
| 代码、表格和长链接容易挤宽消息 | 消息最小宽度约束、长文本换行、代码与表格单独横向滚动 | 源码与样式检查；真实屏宽待视觉验证 |
| 中文输入法确认候选词可能触发发送 | 输入组合期间忽略 Enter 发送快捷键 | 组件测试 |
| 顶部入口多且绝对居中，桌面导航从 768px 就展开 | 中文导航；1180px 以下折叠，移除重复文章入口；菜单可滚动 | 导航切换、Escape、焦点恢复测试；真实屏宽待视觉验证 |
| 首页主要入口位于整屏封面之后 | 改为封面与介绍并排；提供直接复习、写日记入口；六个板块导览 | 生产构建、链接与锚点检查 |
| 博客分类仅为文字标签 | 分类筛选、标题/摘要/标签搜索、结果计数、空结果提示与重置 | 分类与搜索组合筛选测试 |
| 设置打开后焦点留在背后，Tab 可跳出，背景可滚动 | 设置和导航共用焦点循环、Escape、滚动锁与焦点恢复 | 回归测试 |
| 复习题数 max=500 只存在于 HTML，仍可存入 999 | 在更新偏好时限制为 0–500 整数 | 回归测试 |
| 所有页面使用相同浏览器标题 | 随路由更新标题；提供跳到正文入口与导航后的正文焦点 | 路由组件测试 |

保留原有路由、深色绿色风格、数据来源和 localStorage 存储键。未修改已有的股票数据生成脚本和股票页改动。

若部署到新的 Sites 域名，日记、复习进度和 AI 设置仍属于原浏览器的原域名，不会自动迁移到新域名。

后续视觉验收应覆盖 320px、390px、768px、1024px、1440px；检查导航、日记锚点、设置焦点，以及 Markdown 的长代码、长链接和表格滚动。
